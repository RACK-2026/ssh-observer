# Portfolio Notes

## Resume-ready summary
Built a real-time SSH connection observer with Node.js, Socket.IO, configurable collectors, and a dashboard for connection state, heartbeat, and host metrics.

## Highlights

- Split collection, state, proxy, and rendering concerns into small modules.
- Added configurable SSH host/user and agent credentials through environment variables.
- Supports real-time updates and graceful empty-state behavior when a remote host is unavailable.

## Interview focus
Explain polling versus push updates, timeout isolation, safe command execution, and configuration hygiene.

## Public-scope boundary
The public edition contains no private hostnames, passwords, cookies, keys, deployment scripts, or infrastructure screenshots.
